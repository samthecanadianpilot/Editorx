EditorX — Project Roadmap
Last updated: 2026-05-16 · samthecanadianpilot/Editorx · editorx-beta.vercel.app

EditorX

A precise, tactile, browser-based video editor that feels professional without requiring a download or a beefy workstation. Real video pipeline. Real auth. Real cloud storage. No fake demos.

1. Today — What's shipped Live

Editor core

  • Multi-track timeline (V1/A1/T1) with drag, trim, snap, collision protection, blade-tool splitting.
  • Library → Timeline drag-and-drop; OS file drop onto track lanes.
  • Library thumbnails — first-frame for video, the image itself for images, icon for audio.
  • Real video playback to a canvas viewer with proper aspect-fit, transform, per-clip CSS-filter effect, and LUT compositing.
  • Playhead is driven by the active video's currentTime (video is source of truth) — no more re-seek stutter.
  • 17 LUTs with live-graded preview swatches; 10 transitions with animated CSS preview thumbnails; 13 standalone effects.
  • 7 mask types (Rectangle / Ellipse / Bezier / Gradient / Feathered / Animated / Inverted) with drag, corner-handle resize, animated keyframes.
  • Text clips with ~250 Google Fonts, color picker, transform; smart guides snap to canvas center, thirds, and edges with red alignment lines while dragging.
  • Speech-to-text dictation directly into the title text field; text-to-speech preview button.
  • Right-click clip context menu: Detach Audio / Duplicate / Delete.
  • Undo / redo, autosave (debounced 600 ms).
  • Export: WebM always; MP4/H.264 where the browser supports it; .editorx.json project files. Dynamic format detection.

Dashboard + projects

  • Real GitHub OAuth sign-in (no demo).
  • Projects Dashboard with thumbnails, "edited X ago" stamps, per-card menu (Open / Rename / Delete).
  • New-Project modal with 9 size presets (YouTube 1080p / 4K, TikTok, Reel, IG Square, IG 4:5, LinkedIn, X, Custom).
  • Dynamic viewer canvas dimensions per project — 9:16, 1:1, 4:5 render at real dimensions.

Backend

  • /api/auth/github/start + /api/auth/github/callback — real OAuth flow with CSRF state cookie.
  • /api/auth/signout — clears session cookie.
  • /api/me — returns the current user (verifies the cookie's HMAC).
  • /api/projects — list / get / upsert / delete, backed by Vercel KV. Returns clean 503 kv_not_configured if KV isn't enabled; frontend falls back to localStorage automatically.
  • Signed HTTP-only Secure SameSite=Lax session cookies (HMAC-SHA256, 30-day expiry).
  • Local-first cloud sync (cloud.js): every local save schedules a 1.5 s debounced cloud push when signed in. Dashboard hydrates the cloud list on load and merges with local.

Visual / design

  • Fraunces editorial serif site-wide (variable font, italic + roman).
  • Apple Design tokens: #0084FF accent, neutral charcoal scale, 4 px spacing grid, 0.15 s ease-out timing.
  • FCPX-style selection brackets on the selected video clip in the viewer.
  • Scissor cursor + vertical cut-line indicator on the timeline while the Blade tool is active.

  • Real clipping-mask compositing on the canvas (currently DOM outlines only).
  • Per-clip in/out trim that trims source playback (not just width).

Editor UX

Backend

4. Long-term Next quarter

Collaboration

  • Real-time multi-user editing (Yjs + WebSocket relay).
  • Comments anchored to clips or timecodes.
  • Version history with named snapshots and rollback.

AI features

  • Auto-subtitle generation (Whisper).
  • One-click reframe (square / vertical / wide) with face/motion tracking.

Distribution

  • Desktop wrapper (Tauri) for offline editing.
  • Marketplace — shareable LUTs, transitions, title templates.

5. Out of scope Won't do

  • Non-linear effects compositor (After Effects-style node graph).
  • 3D camera / 3D layers.
  • DAW-grade audio mixing (volume + pan + speed is the bar).
  • Hardware-decode optimization for old browsers.

6. Architecture decisions

  • No build step. Plain HTML + ES modules in the browser, plain ESM in Vercel Node functions.
  • Local-first. Everything works offline against localStorage. Cloud sync is an enhancement.
  • Vercel-native. No separate backend service — /api/* is serverless functions; sessions are signed cookies; storage is Vercel KV; media will be Vercel Blob.
  • Honest auth. HMAC-SHA256-signed cookies, HttpOnly + Secure + SameSite=Lax.
